# Typefield Releases

Compiled release builds of [Typefield](https://github.com/securityjeff/mdedit) — a
fast, beautiful developer text editor with best-in-class Markdown.

This repository holds no source code. It exists only so the app's own
in-app updater can download a new build without authenticating to the
private source repository, which GitHub's API otherwise requires even for
just listing releases.

See [Releases](../../releases) for downloadable builds.
